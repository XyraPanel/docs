## Prerequisites

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git
npm install -g pnpm
```

## Corepack

Update `Corepack`:

```bash
npm install --global corepack@latest
```

Enable it for `pnpm`:

```bash
corepack enable pnpm
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/XyraPanel/panel.git
cd panel
cp .env.example .env
```

## Environment Variables

<code-collapse name="Full .env Configuration">

Set up your `.env` file before installing dependencies:

```env [.env]
# XyraPanel Settings
APP_NAME="XyraPanel"

# Environment settings
NODE_ENV="development"
DEBUG=false

# Database
# Set DB_DIALECT=sqlite for local dev or postgresql in production
DB_DIALECT="sqlite"
DRIZZLE_DATABASE_URL="file:./data/XyraPanel.sqlite"

# Auth Origin - Set to your panel URL in production
BETTER_AUTH_URL=http://localhost:3000
BETTER_AUTH_TRUSTED_ORIGINS=http://localhost:3000
NUXT_PUBLIC_APP_URL=http://localhost:3000

# Generate a strong secret with: openssl rand -base64 32
BETTER_AUTH_SECRET=

# Redis
REDIS_HOST="localhost"
REDIS_PORT="6379"
# REDIS_USERNAME=""
# REDIS_PASSWORD=""
# REDIS_TLS="false"

# Security
NUXT_SECURITY_CORS_ORIGIN=""
NUXT_SECURITY_CONNECT_SRC=""

# Captcha Provider (turnstile, recaptcha, or hcaptcha)
CAPTCHA_PROVIDER="turnstile"

# Cloudflare Turnstile
NUXT_TURNSTILE_SECRET_KEY=""
NUXT_PUBLIC_TURNSTILE_SITE_KEY=1x00000000000000000000AA # Test Mode Key

# Google reCAPTCHA v3
# NUXT_RECAPTCHA_SECRET_KEY=""
# NUXT_RECAPTCHA_MIN_SCORE="0.5"

# hCaptcha
# NUXT_HCAPTCHA_SECRET_KEY=""
# NUXT_HCAPTCHA_SITE_KEY=""

# Request Limits (MB)
NUXT_MAX_REQUEST_SIZE_MB="10"
NUXT_MAX_UPLOAD_SIZE_MB="20"
```

</code-collapse>

## Install and Run

Now install dependencies and start the development server:

```bash
mkdir -p data
pnpm install
pnpm run db:push
pnpm dev
```

The panel will be available at `http://localhost:3000`

## Available Commands

| Command | Purpose |
|---|---|
| `pnpm dev` | Start dev server with hot reload |
| `pnpm lint:fix` | Fix linting issues |
| `pnpm test` | Run tests |
| `pnpm db:generate` | Generate database migrations |
| `pnpm db:push` | Apply database migrations |
