XyraPanel uses **Drizzle ORM** with support for SQLite in development and PostgreSQL in production.

::warning
Database deployment docs are still in development
::

## Database Setup

Local development uses the `better-sqlite3` driver that ships with the repo, so a separate `sqlite3` system package isn’t required.

## SQLite for Development

### Configure

Update your `.env` file with SQLite settings:

```env [.env]
DB_DIALECT="sqlite"
DRIZZLE_DATABASE_URL="file:./data/XyraPanel.sqlite"
```

### Initialize

```bash
mkdir -p data
pnpm run db:push
```
