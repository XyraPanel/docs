XyraPanel uses **Drizzle ORM** with support for SQLite in development and PostgreSQL in production.

## Database Setup

XyraPanel uses `better-sqlite3` for local SQLite development. You can optionally install `sqlite3` separately if needed:

```bash
sudo apt install -y sqlite3
```

## SQLite for Development

### Configure

Update your `.env` file with SQLite settings:

```env [.env]
DB_DIALECT="sqlite"
DRIZZLE_DATABASE_URL="file:./data/XyraPanel.sqlite"
```

### Initialize

```bash
mkdir -p data
pnpm run db:push
```
